# Vianelli Drinks

Site responsivo em português com fotos do projeto e carta pesquisável de 28 drinks.

## Desenvolvimento

Requer Python 3. Sem dependências externas ou instalação de pacotes.

```sh
cd /workspace/Vianelli-Drinks
npm run dev
```

Alternativa sem Node: `python3 -m http.server 3000 --bind 0.0.0.0`.

`npm run check` verifica a sintaxe do JavaScript. O site pode ser hospedado como arquivos estáticos em qualquer hospedagem compatível. Contatos: WhatsApp (31) 97114-0579 e Instagram @vianelli_drinks. Atendimento: Entre Rios de Minas e região.

Os arquivos JPEG e PDF originais foram preservados. As imagens WebP em `assets/` são versões otimizadas das fotos fornecidas. A carta e os ingredientes foram transcritos do PDF original; não há preços informados no material.
